# 版本日志

当前项目版本为 **0.8.0**（以 `pyproject.toml` 为准）。完整、可追溯到 Pull Request 的历史请查看仓库中的 [CHANGELOG.md](https://github.com/datawhalechina/torch-rechub/blob/main/CHANGELOG.md) 和 [GitHub Releases](https://github.com/datawhalechina/torch-rechub/releases)。

## 0.8.0（2026-05-12）

- 更新 DIEN 文档、示例与 AUGRU 实现。
- 重构 BST Transformer 处理，并将项目声明的最低 PyTorch 版本调整为 1.10。
- 调整 Embedding 输出和 ONNX 标量解包行为。
- 完善发布元数据、文档图片、教程与 `CITATION.cff`。

## 历史版本

- **0.7.0**：增加自动 API 文档流程、ONNX dynamo/fallback 导出，并修复 MIND/ComiRec list-wise 输出形状。
- **0.6.0**：增加 NPU 相关支持、MMOE/ESMM 教程与更多模型文档。
- **0.5.0**：增加 TIGER、RQ-VAE 以及 Embedding `padding_idx` 支持。
- **0.4.0 及更早版本**：请查看上方完整日志。
