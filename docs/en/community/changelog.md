# Changelog

The current project version is **0.8.0**, as declared in `pyproject.toml`. For the complete history with Pull Request references, see the repository [CHANGELOG.md](https://github.com/datawhalechina/torch-rechub/blob/main/CHANGELOG.md) and [GitHub Releases](https://github.com/datawhalechina/torch-rechub/releases).

## 0.8.0 (2026-05-12)

- Updated DIEN documentation, examples, and the AUGRU implementation.
- Refactored BST Transformer handling and changed the declared minimum PyTorch version to 1.10.
- Adjusted embedding outputs and ONNX scalar-unwrapping behavior.
- Improved release metadata, documentation images, tutorials, and `CITATION.cff`.

## Earlier Versions

- **0.7.0**: Added the automated API-documentation flow and ONNX dynamo/fallback export, and fixed MIND/ComiRec list-wise output shapes.
- **0.6.0**: Added NPU-related support, MMOE/ESMM tutorials, and more model documentation.
- **0.5.0**: Added TIGER, RQ-VAE, and embedding `padding_idx` support.
- **0.4.0 and earlier**: See the complete changelog linked above.
